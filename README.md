# Motiora

Motiora est un logiciel pour Windows qui fabrique des vidéos, des formations, des podcasts et des publicités (montage automatique, voix, sous-titres, animations, retouche de photos et de vidéos, publication sur vos comptes). Il fonctionne **sur votre ordinateur**.
